Initial public release.

- Automatic Markdown literature notes for Zotero personal and locally available group libraries.
- A title-based literature dashboard and links between Zotero and Obsidian.
- Configurable vault location, preservation of handwritten notes, and renamed-note support.
- Original plugin logo, English/Korean setup instructions, and MIT license.

Install the `.xpi` asset through Zotero's Tools → Plugins menu, then use Tools → Zotero–Obsidian Connector: Configure… to choose a vault and notes folder.

Requires Zotero 9.0.x and Obsidian desktop. Tested on Windows; see docs/VALIDATION.md for the exact scope and remaining UI/platform checks. This is an early release.
