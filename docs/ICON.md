# Icon

The interlocking coral-red paper shape and amethyst crystal represent reference management connected to linked notes. This is an independent mark, not a reproduction of either product's official logo.

Generated using the built-in image-generation tool. The master is `assets/icon.png`; transparent PNG variants are included at 32, 48, 96, 128 and 256 pixels. Image metadata was stripped during packaging. The artwork is included under this project's MIT license to the extent applicable.

## Generation prompt

Use case: logo-brand. Create one polished square app/plugin icon for an independent open-source project called Zotero–Obsidian Connector. No text or letters. A bold compact interlocking connector mark made of two folded ribbon/document shapes: one warm coral red, one saturated amethyst purple, forming a clear diagonal link with a small negative-space opening. Subtle geometric facets suggest a paper page and a mineral crystal, without copying existing official logos. Modern precise vector-like silhouette, restrained two-color shading, no tiny details, readable at 32px. Center mark occupying about 80 percent of square, generous clean margin. Transparent background, no mockup, no frame, no watermark, no glow, no shadow.
